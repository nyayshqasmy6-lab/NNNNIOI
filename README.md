# PIANOT — Front-end website

- تمام صفحه‌ها HTML مستقل هستند.
- استایل مشترک: `css/style.css`
- تعاملات فرانت‌اند: `js/main.js`
- صفحات مدیریت: پوشه `admin`

برای اجرا، `index.html` را باز کنید یا از افزونه Live Server در VS Code استفاده کنید.

**محدودیت نسخه:** این پروژه فرانت‌اند نمایشی است. سبد خرید و علاقه‌مندی‌ها در مرورگر با localStorage کار می‌کنند؛ اما احراز هویت امن، ثبت سفارش واقعی، درگاه پرداخت، دانلود فایل‌های خریداری‌شده و داده‌های واقعی پنل مدیریت به بک‌اند و پایگاه داده نیاز دارند.


به‌روزرسانی: انتقال داخلی بین صفحه‌ها نرم‌تر شده و هر گروه از صفحه‌ها رنگ‌بندی و چیدمان بصری متفاوتی دارد.


## به‌روزرسانی رابط کاربری
- هدر و منوی موبایل در تمام صفحات یکپارچه و واکنش‌گرا شده‌اند.
- تایپوگرافی فارسی، فاصله‌گذاری، اندازه تیترها و کارت‌ها بازتنظیم شده است.
- رنگ‌ها با پالت نهایی PIANOT هماهنگ شده‌اند: سبز جنگلی، سبز مریم‌گلی، طلایی شامپاینی، بژ گرم و سفید ملایم.
- جست‌وجوی صفحه نتایج اکنون عبارت جست‌وجو را نمایش می‌دهد و محصولات منطبق را فیلتر می‌کند.
- دسترسی‌پذیری منوی موبایل و حالت فوکوس صفحه‌کلید بهبود یافته است.
- انیمیشن ورود صفحات سبک‌تر شده تا از افکت‌های سنگین و محوکننده جلوگیری شود.

برای بررسی، پوشه را از حالت فشرده خارج کنید و `index.html` را با Live Server اجرا کنید.
